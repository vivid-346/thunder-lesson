# Codex 向け作業ルール（pachinko/）

このフォルダは「P THUNDER 雷牙」（1ファイル完結の3Dパチンコ試作）です。
まず `AI_HANDOFF.md` を読んで、スペック・コード構成・演出の組み立てを把握してください。

## 役割分担

- **Codex**：レビューと実装を担当します。
- **Claude（Claude Code）**：作業を依頼し、変更を確認して、テスト・コミット・GitHub へのプッシュ・スマホ用リンクの更新を行います。
- **ユーザー**：方向を決め、実際に遊んで確認します。

## 守ること

- **コミットとプッシュはしない**でください。変更は作業ツリーに残し、Claude が確認してからコミットします。
- 作業するブランチは `claude/3d-pachinko-prototype-a3fy9m` です。別のブランチを作らないでください。
- ゲームは **`index.html` の1ファイル完結**を保ちます。外部ファイルを増やす場合は、先に相談してください。
- `const CAB_IMG = "data:image/webp;base64,...` の行（埋め込みの筐体画像）は、**読まずに飛ばし、変更しない**でください。非常に長い行です。
- `PINS`（画像から検出した釘の座標）と盤面の線分 `segP(...)` を変えると、入賞率が変わります。変えた場合は必ずテストで入賞率を確認してください。
- スペック（`SPEC`：1/319.9、RUSH突入50%、ST16回・1/9.9、10R×10C×15発）は、依頼がない限り変えないでください。
- 既存作品のキャラクター・ロゴ・名前・楽曲は使いません。キャラクターはオリジナル（雷牙、黒雲獣ゴウマ）です。
- Three.js は r160 を CDN（`cdn.jsdelivr.net/npm/three@0.160.0`）から読み込みます。ほかのライブラリは追加しないでください。
- 画面の文字は日本語です。台の外へ漂う演出は避け、演出は液晶・役物・枠ランプの中に収めます。カメラは固定です。

## テスト（作業の最後に必ず実行）

```bash
cd pachinko
npm install                 # 初回のみ（three@0.160.0 を入れます）
node tests/check.cjs --quick   # 読み込み・物理・当り方A（約1分）
node tests/check.cjs           # 全項目：当り方 A/B/C/D/F まで（約5分）
```

確認する内容：ページエラーがない、左打ちのヘソ入賞率（ハンドル65で6〜15%）、右打ちの電チュー・アタッカー入賞、当り方ごとに「大当り → ラウンド → 終了」まで進むこと。
液晶の大当り画面の画像は `tests/out/` に保存されます。Playwright と Chromium が必要です。

## 報告の形式

### 実装したとき
1. 変更点（関数名と、何をどう変えたか）
2. テスト結果（`check.cjs` の出力をそのまま）
3. 確認できていない点（音、実機の手触りなど）

### レビューのとき
重要度の高い順に、各件を「重要度（高/中/低）・場所（関数名）・問題・具体的な直し方」で書いてください。推測の場合はそう明記してください。
