# 雷のしくみ — 光った。まだ、鳴らない。

専門知識のない大人向けの、12章・標準約3分20秒のインタラクティブ解説です。
雷雲の帯電、放電路の成長と枝分かれ、帰還雷撃、空気の加熱と音波、光と音の時間差、雷鳴が長く響く理由まで説明します。

## 見る

`index.html` をブラウザーで開いてください。画像と日本語の仮ナレーションを `assets/` に同梱しており、外部ライブラリーのインストールは不要です。
ローカルWebサーバーから同じフォルダーを配信しても動作します。

## 内容と操作

再生・一時停止、シーク、章選択、速度変更、音声切替、シアター表示、距離による到着時間の比較、確認問題3問。
音速340m/sを用いた距離の計算は説明用の概算で、安全な距離の判定には使えません。
背景は生成した演出素材で、気象観測映像ではありません。放電・電荷配置・粒・波の形と速度は模式表現です。
研究・説明の根拠は教材末尾と台本に記載しています。

## リポジトリの独立性

雷教材専用です。旅行計画アプリ `vivid-346/tabi-planner` のコード、設定、配信設定を含めません。
ルートの自動デプロイ設定や外部サービスへの送信処理は追加していません。

## 別プロジェクト：3Dパチンコ プロトタイプ（`pachinko/`）

`pachinko/index.html` は1ファイル完結の3Dパチンコ「P妖怪召喚 ドキドキRUSH」です（Three.js r160 をCDNから読み込み）。
妖怪テーマのオリジナル台で、既存作品のキャラクター・ロゴ・楽曲は使っていません。

```bash
cd pachinko
python3 -m http.server 8000   # → http://localhost:8000/
```

ES Modules と import map を使うため、ローカルサーバー経由で開いてください（初回のみ CDN 接続が必要です）。

| 項目 | 値 |
| --- | --- |
| 通常時大当り | 1/319.9 |
| RUSH突入率 | 50%（奇数図柄はRUSH確定、偶数図柄は大当り後に昇格PUSH演出） |
| 妖怪RUSH | ST16回・1/9.9 → 継続率 約81.8%（電サポ付き・右打ち） |
| 出玉 | 10R × 10カウント × 15発 ≒ 1500発 |
| 賞球 | ヘソ 3発 / 電チュー 1発 |

- 盤面は2D物理（釘・風車・ワープ・ステージ・ヘソ・電チュー・アタッカー）を3Dで描画しています。ヘソ入賞率は左打ちのハンドル50〜55付近で約9%です。
- 先読み：保留色は白・青・緑・赤・金。赤・金保留では画面とカメラが大きく揺れ、端末を振動させます（`navigator.vibrate`）。
- 群予告「妖怪大行進」は大当り時の50%、または赤・金保留ハズレ時の35%で発生します。
- SP「妖怪召喚リーチ」：魔法陣、回転リング、発光コア、粒子、光柱、降臨する召喚メダル役物、カットイン → 巨大PUSHボタン。
- 大当り：プチュン（暗転＋無音）→ 白フラッシュ → 虹エフェクト → ファンファーレ → ラウンド消化 → RUSH突入/昇格演出。
- 効果音・BGMはWebAudioで合成しています。音声はブラウザーの読み上げ機能を使い、ボタンでオフにできます。
- 調整用：HUDの「デモ 1/30」「次回 大当り」、コンソールの `__sim(power, n)`（ヘソ入賞率などをヘッドレス計測）。
