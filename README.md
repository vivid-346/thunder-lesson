# 雷のしくみ — 光った。まだ、鳴らない。

専門知識のない大人向けの、12章・標準約3分20秒のインタラクティブ解説です。
雷雲の帯電、放電路の成長と枝分かれ、帰還雷撃、空気の加熱と音波、光と音の時間差、雷鳴が長く響く理由まで説明します。

## 見る

`index.html` をブラウザーで開いてください。画像と日本語の仮ナレーションを `assets/` に同梱しており、外部ライブラリーのインストールは不要です。
ローカルWebサーバーから同じフォルダーを配信しても動作します。

## 内容と操作

再生・一時停止、シーク、章選択、速度変更、音声切替、シアター表示、距離による到着時間の比較、確認問題3問。
音速340m/sを用いた距離の計算は説明用の概算で、安全な距離の判定には使えません。
背景は生成した演出素材で、気象観測映像ではありません。放電・電荷配置・粒・波の形と速度は模式表現です。
研究・説明の根拠は教材末尾と台本に記載しています。

## リポジトリの独立性

雷教材専用です。旅行計画アプリ `vivid-346/tabi-planner` のコード、設定、配信設定を含めません。
ルートの自動デプロイ設定や外部サービスへの送信処理は追加していません。
